# Mini E-Commerce

HTML, CSS ve JavaScript kullanılarak geliştirilmiş basit bir
e-ticaret uygulaması.

## Özellikler
- Ürün listeleme
- Ürün arama
- Kategori filtreleme
- Sepete ürün ekleme
- Ürün silme
- Ürün adetini değiştirme
- Toplam fiyat hesaplama
- Responsive tasarım
- LocalStorage ile sepet kaydetme

## Kullanılan Teknolojiler
- HTML5
- CSS3
- JavaScript
